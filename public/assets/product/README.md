# Product images (later use)

Lifestyle and detail photos for marketing, Amazon listings, and future **Build a Coloring Dictionary** UI. These are **not** print interiors.

| Folder | Use |
|--------|-----|
| `lifestyle/` | Adults, kids, family coloring in context |
| `detail/` | Close-ups (pencils, texture) for heroes / accents |

Registry metadata lives in `public/data/seed/assets.json` (`kind`: `product_lifestyle` \| `product_detail`, `isProductImage: true`, `audience`, `labels`).

Concept book interiors live in `../previews/` (`interior_preview` · marketing mockups · not print-ready).
