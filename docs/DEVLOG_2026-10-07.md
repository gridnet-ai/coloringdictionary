## Executive summary

Today the project moved from a single-content site to a **multi-database publishing platform** with large dictionary corpora on GCS, flower meanings isolated in a named Firestore database, an **English Word Database** (`englishwords`, Kaikki/Wiktionary sheet, ~1.49M entries), year-stamped definition history, owner import APIs, shop/cart/Stripe checkout, and marketing/UI polish (brand icons, sticky header, carousel UX, coloring-book hero type).

## Architecture notes

```
GCS corpora ──import APIs──► Firestore (default)   lemmas / entries / definitionEditions
TerryList JSON ──import──► Firestore (floriography) entries / dictionary1884
```

Definition history rule: **append** editions by `year` + content hash; never delete prior years so historical backfill remains possible.
